# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Comprehensive test coverage with Vitest
- CI/CD pipeline with GitHub Actions
- Type-safe API service layer
- Custom React hooks for better code organization
- Professional README with badges and detailed setup instructions

### Changed
- Upgraded to TypeScript strict mode
- Refactored components for better maintainability
- Improved error handling and user feedback
- Enhanced responsive design

### Fixed
- TypeScript compilation errors
- API error handling edge cases
- Mobile responsiveness issues

## [1.0.0] - 2024-10-17

### Added
- Initial release of NewsReal
- AI-powered news podcast generation
- Support for 10+ news categories
- 5 different tone options for podcast style
- Local news integration with location search
- Full-featured audio player with speed controls
- Real-time generation progress tracking
- Responsive UI with ShadcnUI components
- Integration with NewsAPI, OpenAI, and ElevenLabs
- Environment-based configuration
- Dark/light theme support

### Technical Features
- React 18 with TypeScript
- Vite build system
- TailwindCSS styling
- Radix UI components
- React Router for navigation
- TanStack Query for state management

### Security
- Environment variable based API key management
- Input validation and sanitization
- CORS protection
- Secure API communication
